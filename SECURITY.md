# Security policy

## Public scope

This repository is a clean, offline portfolio derivative. It contains fictional product data and a credential-free n8n workflow. It must not contain:

- production workflow exports or execution history;
- affiliate links, account identifiers, or private product research;
- API keys, credential references, Google document IDs, or cloud project IDs;
- private hostnames, IP addresses, filesystem paths, or generated media;
- personal email addresses or service-account addresses.

## Safe use

- Import the demo only into an n8n instance you control.
- Review a workflow before activating it.
- Keep credentials in n8n's credential store, never in workflow JSON.
- Use official platform APIs or user-supplied source material; do not add scraping that violates platform terms.
- Keep generation and publishing disabled until cost, rights, disclosure, and human-review controls are configured.

## Reporting a concern

If a value appears to expose private or sensitive information, do not reuse it. Open a GitHub security advisory or contact the owner through the public GitHub profile.
