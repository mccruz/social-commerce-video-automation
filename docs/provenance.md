# Provenance and public/private boundary

## What this repository is

This is a clean-history portfolio derivative of a private, self-hosted n8n proof of concept. It preserves the high-level workflow decisions and deterministic extraction/ranking approach.

## What was replaced

The public artifact was constructed separately and does not contain a raw production export. It replaces:

- real products, sellers, metrics, affiliate links, and media with fictional fixtures;
- Google Sheets nodes and document identifiers with an offline input node;
- credential references and cloud-project metadata with no credentials;
- provider HTTP nodes with a disabled adapter receipt;
- generated video, file paths, provider responses, and execution identifiers with no media;
- live platform handoffs with a non-publishing preview.

## Evidence boundary

The repository demonstrates executable local orchestration, parsing, deterministic scoring, creative-plan construction, and safety gates. It does not demonstrate current marketplace retrieval, paid model availability, production publishing, affiliate revenue, or conversion lift.

Historical private canary work is intentionally not used as public runtime evidence. The public claim is narrower: the credential-free workflow and its offline harness execute successfully with fictional inputs.
